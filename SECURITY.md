# Security policy

KeyLane is an early-stage self-hosted project. Please do not publish provider credentials, database files, prompts, or exploitable vulnerability details in public issues.

After the repository is published, maintainers should enable GitHub private vulnerability reporting. Use **Security → Report a vulnerability** for a private report. Until that channel is enabled, do not submit sensitive vulnerability details through public issues.

When reporting an issue, include the affected commit or release, deployment method, impact, and a minimal reproduction that contains no real credentials or private prompts.
